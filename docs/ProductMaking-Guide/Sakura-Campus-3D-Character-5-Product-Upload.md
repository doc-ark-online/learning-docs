## 商品上传

**第一步：** 选中要上传的 Prefab，依次选择“樱校中文功能入口”→“CharaMake 预览”。

![5.1 商品上传示意图 96](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-116.webp)

**第二步：** 单击预览界面的登录按钮。

![5.1 商品上传示意图 97](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-117.webp)

**第三步：** 选择任意一种登录方式。登录完成后关闭页面。

|  |  |
| :---: | :---: |
| ![5.1 商品上传示意图 98](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-118.webp) | ![5.1 商品上传示意图 99](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-119.webp) |

**第四步：** 在预览界面填写商品名称并保存，根据取景框制作 UI 图并保存，然后单击“发布商品”。

![5.1 商品上传示意图 100](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-120.webp)

**第五步：** 填写商品详情和创作说明，设置售价，检查商品目录是否正确，然后单击“发布商品”。创作说明和售价为必填项。

![5.1 商品上传示意图 101](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-121.webp)

**第六步：** 等待上传完成，确认页面显示上传成功。

|  |  |
| :---: | :---: |
| ![5.1 商品上传示意图 102](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-122.webp) | ![5.1 商品上传示意图 103](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-123.webp) |

**第七步：** 登录[创作者中心](https://portal.ark.online/#/admin/home)，依次进入“资源”→“我的资源”。

![5.1 商品上传示意图 104](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-124.webp)

**第八步：** 进入“游戏模组”→“商品列表”，查看商品状态并等待审核。审核时效约为 1～2 天。

![5.1 商品上传示意图 105](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-125.webp)

::: tip 查看已上传资源

在 Unity 顶部菜单依次选择“工具”→“MetaApp”→“Creator”，可以查看已上传资源列表。

:::

![5.1 商品上传示意图 106](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-126.webp)

相关法律责任由创作者承担，包括但不限于返还从 233 乐园获得的全部收益，并赔偿因此产生的损失。

包括律师费、诉讼费、保全费和差旅费等合理支出。

:::

### 人物装扮类

#### 资源审核

- 与默认角色形象不匹配不贴图，存在变形位移的资源

- 完成度极低和破损的资源

- 超过樱花校园资源制作教程规定配置的资源（如修改肤色、多边面个数）

- 已上线资源重复上线

- 互动（走跑跳躺下）露出隐私部位、变形翻折验证

- 服装变色资源变色数量与槽位不匹配

- 服装、发型不可携带眼镜、发/头饰、面具、眼睛、翅膀、尾巴等饰品

- 服装必须制作鞋子

- 发型必须开启换色功能

- 同款资源不得换色重新上传

- 与过去作品相似度极高

- 相同商品不得女性男性一起上传

- 盗用或剽窃他人作品

- 未授权商用作品（包括但不限于未得授权将动漫、游戏或影视角色的服化道妆资源用于售卖盈利）

#### 商品缩略图（用于游戏内）

- 与对应商品无关

- 超过樱花校园资源制作教程规定配置

- 夸大或P图商品性质的图片

- 含有文字

- 不完整

- 颜色与商品不符合

- 不可变色商品颜色与商品默认穿戴一致

- 背景底色必须为淡紫色的默认预览颜色

- 朝向统一为15°向左（大致）

- 服饰必须T-pose（即抬手默认姿态）、带鞋展示（无鞋则展示出脚部）

- 发型仅展示饱满头部、脖子和少量衣服；长发可截图至胸前

![商品缩略图（用于游戏内）示意图 107](https://arkimg.ark.online/sakura-campus-3d-guide-20260828-127.webp)

#### 详情图（用于详情页）

- 商品详情图最多可添加 5 张，至少添加 1 张。

- 第 1 张商品详情图将自动作为用户端列表中的创作内容首图。

| 项目 | 要求 |
| --- | --- |
| 图片比例 | `1:1`、`16:9` 或 `9:16` |
| 图片格式 | JPG、PNG、WebP 或 GIF |
| 文件大小 | JPG、PNG、WebP 大于 200 KB 时会被压缩；GIF 不得超过 200 KB |

##### 服装类型

- 首图必须展示出服装的着装效果，需展示出角色，可使用半身/全身构图；

- 至少有 1 张能展示完整的着装效果，要求包括：发型、角色、服装、鞋子、手；

- 不得出现只有独立肢体，如聚焦腿部、脚步特写、身体躯干特写（手指上存在美甲除外）；

#### 商品命名与创作描述

- 与商品无关的名称或说明

- 扭曲、夸大商品性质

- 有错别字和错误的描述

- 与特定人物相关（公众人物、历史人物）

- 敏感话题文字

- 可能引发社会非议文字

- 网页链接与长数字
