# 面部绘制挂件模型

面部绘制挂件是一种特殊的动态饰品，你可以基于面部绘制基础模型，修改贴图制作新的面部绘制挂件，无需搭建骨骼并且绑定。

**面部绘制基础模型：**

女性基础挂件：https://arkimg.ark.online/SK_Cartoon_Female_editableface_000.zip



## 模型规范：

- 可以基于基础面具模型，修改面具形状
- **不能对体型比例进行修改。**
- 每个面部绘制最多支持三个材质球。
- 材质不支持双面显示



## 贴图规范

- 面部绘制商品使用服装材质，详情参考[服装材质](https://learning.ark.online/ProductMaking-Guide/5_3_0_Clothing-material.html)



### 贴图尺寸：

- 贴图最大不能超过1024*1024
- 可支持透贴效果



## 完成：

- 贴图设置完成之后，即可进行上传操作。
