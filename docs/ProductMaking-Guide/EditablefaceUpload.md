# 面部绘制饰品上传

- 资源配置完成后，可以点击资源上传，等待审核完成后直接上传到素材库，并在创作者中心查看资源上传进度。

- **上传后资源不能更新，如果对资源进行修改，只能重新上传**

- 同步到本地的资源**不能直接覆盖更新**，如对资源修改需要重新导入上传

  

## 资源导入

- 基本步骤与[动态饰品上传 | 教程](https://learning.ark.online/ProductMaking-Guide/7_7_0_Dynamic-accessories-upload.html)一致，面部绘制饰品可以不用添加动态骨骼与物理效果。

- 面部绘制饰品商品使用服装材质，详情参考[服装材质](https://learning.ark.online/ProductMaking-Guide/5_3_0_Clothing-material.html)

  

### 导入步骤

点击资源导入，选择需要导入的文件

![image-20260724132445400](https://arkimg.ark.online/image-20260724132445400.webp)

导入时选择“动态挂件”部位。

<img src="https://arkimg.ark.online/image-20260716000126844.webp" alt="image-20260716000126844" style="zoom:67%;" />

贴图类型请选择“模型贴图”

![img](https://arkimg.ark.online/1739959349363-1.webp)

导入后即可点击模拟按钮，预览穿戴效果

![image-20260724151517605](https://arkimg.ark.online/image-20260724151517605.webp)
